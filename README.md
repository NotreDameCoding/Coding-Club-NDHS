# Coding Club Website

NDHS CODING CLUB WEBSITE

## Files
- `index.html`: page structure
- `style.css`: how it looks
- `script.js`: builds the Home cards and the Meetings, Concepts, and Members sections from the data, and switches between tabs
- `data.js`: information held on the site (members, meetings, and the concept each meeting teaches)
- `games.js` and `games.css`: the Coding Games (Booleans, HTML Tags, Flexbox)

## How to add yourself
- Go to Data.js
- Click the pencil to edit
- Copy the line of code from the member above you
- Replace their name with yours
- Click commit changes then propose changes
- Done!
